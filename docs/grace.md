# CIRISGrace

**CIRISGrace** runs the daily readiness gates for the CIRIS ecosystem. One command answers *"can I cut from the substrate today, and if not, what is in the way?"*

Grace is an orchestration surface, not a verification authority. [CIRISConformance](https://github.com/CIRISAI/CIRISConformance) decides what "correct" means and proves it against real published wheels. Grace assembles the results, asks the questions and reports. It cannot change what passing means: the dependency runs one way, as a wheel does to a gate.
