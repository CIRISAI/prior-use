# Conscience (CIRIS architectural component)

In the CIRIS framework, **conscience** is the named runtime evaluation faculty that checks candidate actions against the framework's embedded principles before those actions are taken. It is implemented in CIRIS as the [H3ERE](h3ere.md) conscience module, with a Coherence faculty that detects contradictions across time and context against the agent identity.

## Scope of priority claim

"Conscience" is a common English word with very wide prior use across philosophy, theology, law, and ordinary speech. CIRIS does **not** claim and could not claim priority on the word itself. This record documents only its CIRIS-specific use as a named runtime evaluation faculty within the CIRIS architecture, and the dates at which that specific architectural use was published.
