# RATCHET (Reference Architecture for Testing Coherence and Honesty in Emergent Traces)

**RATCHET** is the named CIRIS reference architecture for evaluating CIRIS-aligned agent traces against the [Coherence Ratchet](coherence-ratchet.md) mechanism. It provides the computational machinery that accumulates coherence constraints across a trace history and computes coherence-collapse statistics.

## Subsequent significant uses
