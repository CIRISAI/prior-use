# CIRIS Accord

The **CIRIS Accord** is a sister document to the [CIRIS Covenant](covenant.md). The current published version is *Accord v1.2-Beta — Working Draft (Open to Adversarial Review)*. The Accord canonicalizes the framework's six foundational principles and the meta-goal [M-1 (Adaptive Coherence)](m1-adaptive-coherence.md), and provides the Books that operationalize them — Integrity, Resilience, Incompleteness Awareness, Sustained Coherence, Principled Ethical Existence, Ethical Obligations, Ethical Citizenship, Path Toward Ethical Maturity.
