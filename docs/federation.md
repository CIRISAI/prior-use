# CIRIS Federation

The **CIRIS Federation** is the named architecture by which independently operated CIRIS-aligned deployments interoperate, exchange signed traces, and provide mutual structural defense via diversity. The federation depends on supporting components including [`CIRISNode`](https://github.com/CIRISAI/CIRISNode), [`CIRISRegistry`](https://github.com/CIRISAI/CIRISRegistry), [`CIRISVerify`](https://github.com/CIRISAI/CIRISVerify), and [`CIRISPersist`](https://github.com/CIRISAI/CIRISPersist). The Federation is the operational substrate for the **Federated Ratchet** mechanism formalized in Book IX of the [CIRIS Accord](accord.md).
