# CIRIS Covenant

The **CIRIS Covenant** is the predecessor and sibling document to the [CIRIS Accord](accord.md). It is a working specification for the day-to-day ethical operation of advanced autonomous systems — covering routine safety, transparency, governance, and resilience requirements. The Covenant is explicit that it is *not*, by itself, sufficient for catastrophic-risk alignment of frontier-level AGI; it governs ordinary operation.
